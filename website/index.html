Frequently Asked Questions

Is FillIt completely free to use? +

Yes! FillIt is 100% free with no hidden subscriptions or paid tiers required.

Does FillIt require API keys? +

No API keys required! FillIt operates using smart fuzzy matching, synonym mappings, and optional on-device WASM models directly in your browser.

Can I export or backup my data? +

Yes, you can export your entire profile and context entries as a standard JSON file at any time from the extension Settings page.
